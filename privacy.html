Política de privacidad de Mi Finanzas

Última actualización: 31 de octubre de 2026.

Mi Finanzas es una aplicación personal, no comercial, destinada a organizar las finanzas de su propietario en su ordenador. Esta página describe el funcionamiento previsto de la aplicación y su integración opcional con Enable Banking.

Datos tratados

Cuando el usuario importa extractos o autoriza una conexión bancaria, la aplicación puede tratar identificadores de cuenta, saldos, fechas, importes, descripciones y categorías de movimientos. La aplicación puede tratar información sobre inversiones si el usuario la introduce.

Finalidad y almacenamiento

Los datos se utilizan para consultar movimientos, evitar duplicados, clasificar gastos, calcular resúmenes y mostrar gráficos. La versión local almacena los datos financieros en una base de datos SQLite en el ordenador del usuario. La página pública de GitHub Pages que aloja este aviso no contiene movimientos bancarios.

Conexión bancaria opcional

Si el usuario decide conectar su banco, Enable Banking actúa como proveedor de conectividad con las entidades financieras y gestiona el flujo de autorización bancaria. La conexión se utiliza para consultar información autorizada por el usuario; no se pretende iniciar pagos. El acceso a las cuentas depende del consentimiento y de las condiciones del proveedor y del banco. Consulta también la política de privacidad de Enable Banking.

Compartición y servicios externos

Mi Finanzas no vende datos financieros. Una conexión bancaria activada implica que el proveedor de conectividad y la entidad financiera intervienen en el intercambio de información autorizado. No se envían movimientos a servicios de inteligencia artificial externos salvo que el usuario habilite expresamente una función que lo requiera y se le explique su alcance.

Conservación, seguridad y eliminación

El usuario controla los datos almacenados localmente y puede exportarlos, realizar copias de seguridad o eliminar la base de datos local. Se recomienda proteger el ordenador y cifrar las copias de seguridad. Las credenciales privadas o tokens de conexión no deben publicarse en repositorios ni archivos compartidos.
